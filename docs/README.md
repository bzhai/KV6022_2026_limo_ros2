## Viewing the simulators on GitHub

GitHub shows `.html` files as source code, so enable GitHub Pages to run the simulators. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, then choose **main** and the **/docs** folder. The site will be at `https://<user>.github.io/<repo>/`, with each task linked from the landing page.
